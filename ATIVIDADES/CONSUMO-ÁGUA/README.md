Sobre:
    Este projeto desenvolvido em Python auxilia uma campanha de concientização ambiental de saneamento (consumo de água).
    O mesmo classifica o perfil de consumo e entrega uma mensagem educativa de acordo com as informações que o morador inserir quando solicitado como: tipo do imóvel e consumo mensal de água em metros cúbicos (m³).

Após as informações, uma mensagem educativa será exibida de acordo com as regras de negócio.

💡 Exemplo
Digite o tipo de imóvel (comercial, casa ou apartamento): apartamento
Digite o consumo mensal de água em m³: 8.5

Consumo econômico – excelente controle de água!
