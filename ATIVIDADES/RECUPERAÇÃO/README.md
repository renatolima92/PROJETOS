#SOBRE 🧐
Este projeto desenvolvido em Python, visa calcular o consumo elétrico de um aparelho.
Para usá-lo o usuário deve informar:
Nome do aparelho ⭐
Potência em watts (W). ⚡
Tempo de uso diário em horas. ⏱

O programa calcula o consumo em kwh/mês e o custo com uma tarifa de R$ 0,75/kwh 💰

Fórmulas 💡
consumo_mensal = (potencia * tempo_de_uso_diário * 30) / 1000
custo_mensal = consumo_mensal * custo_kwh
