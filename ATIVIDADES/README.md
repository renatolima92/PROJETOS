# 🛒 Sistema de Desconto Progressivo
Autor: Renato de Lima Leoncio

Este projeto foi desenvolvido com o objetivo de praticar conceitos básicos de programação através da criação de um sistema de desconto progressivo para uma loja.

O programa solicita ao usuário o valor total da compra, identifica qual faixa de desconto deve ser aplicada, então apresenta o valor do desconto e o total a pagar.

🧮 As regras utilizadas são:
Menor que R$ 200,00, cliente ganha 5% de desconto. 🏷️
De R$ 200,00 até abaixo de R$ 300,00, cliente ganha 10%. 🏷️
Maior ou igual a R$ 300,00, cliente ganha 15%. 🏷️
