# 📊 Pesquisa de Satisfação - TudoWeb

## 📝 Sobre o projeto

Projeto desenvolvido em Python para realizar uma pesquisa de satisfação com os clientes da empresa fictícia TudoWeb.

O programa coleta informações de 50 entrevistados, incluindo nome, idade e opinião sobre o atendimento prestado.

## 🎯 Objetivo

Identificar o grau de satisfação dos clientes por meio de três opções de avaliação:

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

Ao finalizar a pesquisa, o programa apresenta a quantidade de respostas EXCELENTE e RUIM, além das respostas BOM.

## ⚙️ Funcionalidades

- Solicitação do nome do entrevistado.
- Solicitação da idade.
- Registro da opinião sobre o atendimento.
- Repetição da pesquisa para 50 entrevistados.
- Contabilização das respostas utilizando contadores.
- Exibição do resultado final da pesquisa.

## 💻 Conceitos de Python utilizados

- `input()`: entrada de dados.
- `print()`: exibição de informações.
- `for`: estrutura de repetição.
- `if`, `elif` e `else`: estruturas condicionais.
- `+= 1`: incremento dos contadores.
- Variáveis: armazenamento dos dados e resultados.

Ao concluir os 50 entrevistados, o programa apresenta o total de avaliações:

- EXCELENTE
- BOM
- RUIM
