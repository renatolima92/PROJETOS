💧 Controle de Níveis de Água

📌 Sobre o projeto

Desenvolvido utilizando Python.

O objetivo é simular o monitoramento de um reservatório de água, exibindo mensagens de alerta com cores diferentes de acordo com o nível de água.

🎯 Objetivos

Utilizar listas para armazenar os níveis do reservatório.

Criar uma função para definir a cor de cada mensagem.

Utilizar estruturas condicionais (if, elif e else).

Percorrer uma lista utilizando o laço for.

Aplicar cores no terminal com a biblioteca Colorama.
